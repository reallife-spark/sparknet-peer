# Plan → Permission → Execute (EU AI Act Article 14)

Mandatory three-stage gate for human oversight:
1. Plan: Agent compiles read-only proposal/diff
2. Permission: Open WebUI renders interactive Allow/Deny approval cards; unattended requires explicit validation
3. Execute: Operations execute only after human sign-off within strict user privilege boundaries

This satisfies Article 14 (Human Oversight) requirements.
