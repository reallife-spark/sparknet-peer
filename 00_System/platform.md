# platform record

The computer system this node's agents operate on, captured rather than asserted.

Generated by scripts/sparknet-identity-capture.sh in the same run that wrote
manifests/user-env-manifest.json, which this record summarises. Do not edit it by
hand: a hand-edited platform record states what someone believes the host is, and
the capture exists to replace that belief. Re-run the script instead, and both
files move together.

machine is the architecture, and it is the field most worth reading before
assuming a tool, wheel or container image will work here.

running_as_root is a fact about the capturing process, not a permission. This
record grants nothing and widens nothing - naming a platform is descriptive, and
the privilege consequences of the identity captured beside it are enforced
elsewhere, not by this file.
